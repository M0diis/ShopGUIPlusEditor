# Changelog

## 2.1.1

- Fixed editor access for players with command-specific add or edit permissions.
- Shop edits now refuse invalid YAML and keep a `.bak` copy before saving.
- Added serialization for leather colors, vanilla armor trims, fireworks, potion colors, and modern potion types.

## 2.1.0

- Updated compatibility to Paper/Minecraft 26.2 and Java 25.
- Added MiniMessage and legacy `&`/`§` formatting, including RGB colors, across editor text and messages.
- Improved editor inventory click/drag handling and item metadata serialization.
